# Gong Cha Clone Coding

공차 브랜드 웹사이트를 참고하여 제작한 반응형 클론 코딩 프로젝트입니다.

PC / Tablet / Mobile 환경에 맞춰 레이아웃을 구현하고,  
Swiper를 활용한 메뉴 및 신규 매장 슬라이드와 모바일 전용 메뉴 인터랙션을 구현했습니다.

## Live Demo

https://jiwonnn13-hub.github.io/gongcha-clone/

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Swiper.js

## 주요 구현 기능

- 반응형 웹 구현
- PC GNB 및 2Depth 메뉴
- Tablet / Mobile 햄버거 메뉴
- 모바일 Full Screen Navigation
- 모바일 2Depth 메뉴 토글
- YouTube Hero Video
- 메뉴 자동 슬라이드
- Swiper Navigation
- 신규 매장 슬라이드
- Progress Bar
- Hover Interaction

## Responsive

- Desktop
- Tablet
- Mobile

각 디바이스 크기에 맞춰 레이아웃과 콘텐츠 배치를 조정했습니다.

PC에서는 GNB와 2Depth 메뉴를 제공하고,  
Tablet / Mobile에서는 햄버거 메뉴 기반의 전체 화면 내비게이션으로 변경됩니다.

## 구현 목적

브랜드 웹사이트의 레이아웃과 인터랙션을 분석하고 이를 HTML, CSS, JavaScript로 직접 구현하면서 반응형 레이아웃 구성과 웹 퍼블리싱 역량을 연습하기 위해 제작했습니다.
